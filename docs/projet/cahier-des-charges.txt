1. PRÉSENTATION DU PROJET
RuneCast est une application desktop cross-platform (Windows + Linux)
qui traduit les jeux vidéo pour permettre aux joueurs de lire et
comprendre leurs jeux.
- Phase 1 (cette version) : jeux locaux/solo, priorité absolue aux
  jeux Ren'Py.
- Phases ultérieures (hors périmètre v1) : autres moteurs, OCR/overlay,
  puis éventuellement jeux en ligne.
- Mention obligatoire dans l'application : « Créé par HARPUTOGLU
  David, aidé par l'IA » + email kasparof57@gmail.com.

2. IDENTITÉ VISUELLE
- Logo / icône / favicon : rune turcique ancienne (style Orkhon)
  formant la lettre « R », aspect cristallin, couleur TURQUOISE
  dominante, cadre hexagonal.
- Couleur principale de l'interface : turquoise.

3. INTERFACE UTILISATEUR
- Interface ergonomique, intuitive et professionnelle.
- Vrais menus et vrais paramètres (aucun élément factice).
- Thèmes : Turquoise (PAR DÉFAUT), Noir, Sombre, Clair, + thème
  personnalisable et enregistrable (création, sauvegarde et
  rechargement de thèmes personnels).
- Langues de l'interface : langues turciques (turc, azéri, ouzbek,
  kazakh, turkmène, kirghiz — liste exacte à confirmer), arabe,
  français, anglais, espagnol, portugais, italien.
- Support RTL obligatoire pour l'arabe (interface de droite à gauche).
- Distinction importante : langue de l'interface ≠ langues de
  traduction des jeux. L'utilisateur peut traduire un jeu vers toute
  langue supportée par le moteur, même si ce n'est pas une langue de
  l'interface.
- Pages légales traduites dans TOUTES les langues de l'interface :
  Avertissement (disclaimer), À propos, Licence, Crédits.

4. TRADUCTION
- Assistant de premier lancement : choix mode en ligne ou mode 100 %
  local. Modifiable à tout moment dans les paramètres.
- Mode en ligne : Yandex Translate PAR DÉFAUT ; autres moteurs
  disponibles en option dans les paramètres (DeepL, LibreTranslate,
  Google, etc.) ; repli automatique vers le mode local si la
  connexion est perdue.
- Mode local : modèles de traduction installés sur le PC, aucune
  connexion internet requise.
- Matériel cible : PC modeste, 8 Go RAM, CPU uniquement (pas de GPU
  exigé) → modèles légers et quantifiés obligatoires.
- Glossaires dès la v1 : tableau éditable dans l'application,
  sauvegardé PAR JEU, termes imposés (noms de personnages, lieux,
  objets) appliqués partout, protection automatique des variables et
  balises ({nom}, [variable], %s, balises Ren'Py {b}, {i}, etc.).
- Cache de traduction (ne pas retraduire une phrase identique) et
  historique des traductions.

5. PÉRIMÈTRE PHASE 1 : JEUX REN'PY
- Traduire TOUT : dialogues, menus, interface du jeu (boutons,
  options), descriptions.
- Trois modes de travail AU CHOIX de l'utilisateur :
  1) Éditeur intégré avec prévisualisation avant application ;
  2) Traduction entièrement automatique ;
  3) Édition a posteriori des fichiers déjà traduits.
- Deux modes de sortie AU CHOIX de l'utilisateur :
  1) Modification directe des fichiers du jeu, avec sauvegarde
     automatique des fichiers originaux avant toute modification et
     fonction de restauration ;
  2) Génération d'un patch de traduction séparé.
- Technique Ren'Py : extraction des archives .rpa, analyse des
  scripts .rpy, protection des balises/variables Ren'Py, réinjection
  des traductions.

6. ARCHITECTURE ÉVOLUTIVE (hors v1 mais à prévoir)
- Phase 2 : OCR + affichage par overlay sur le jeu ET fenêtre
  flottante, au choix de l'utilisateur.
- Phase 3 : système de plugins pour d'autres moteurs (Unity, RPG
  Maker, etc.).
- Phase 4 (lointaine) : jeux en ligne (chat uniquement au début),
  si techniquement et légalement possible.
- L'architecture v1 doit permettre ces extensions sans réécriture
  complète.

7. DISTRIBUTION ET INSTALLATION
- Windows : RuneCast-Setup.exe (installateur) + RuneCast-Portable.exe
  (portable), testés sur Windows 10.
- Linux : .deb (Debian et dérivés), .rpm (Fedora et dérivés, testé sur
  Fedora 44), .AppImage (portable universel), code source complet.
- Script install.sh intelligent : détecte la distribution (via
  /etc/os-release) et l'architecture, puis propose les formats
  adaptés :
  * Linux Mint / Ubuntu / Debian → choix : .deb, .AppImage, source ;
  * Fedora / Mageia / openSUSE → choix : .rpm, .AppImage, source ;
  * Distribution inconnue → choix : .AppImage, source.
- Le script détecte aussi les dépendances manquantes (ex. libfuse2
  pour AppImage) et propose de les installer.
- Le script propose d'ajouter le dépôt officiel RuneCast (apt/dnf,
  signé GPG) pour les mises à jour système.

8. MISES À JOUR
- Source des mises à jour : GitHub Releases.
- .deb / .rpm : mises à jour via le gestionnaire de paquets du
  système (terminal ou logiciel graphique), comme Firefox ou Chrome,
  grâce au dépôt officiel RuneCast ajouté à l'installation.
- Windows / AppImage / portable : mise à jour automatique intégrée à
  l'application, téléchargement EN ARRIÈRE-PLAN, installation
  silencieuse (ou simple confirmation si droits administrateur
  nécessaires).
- Aucune perte de données utilisateur après mise à jour (thèmes,
  glossaires, profils conservés).

9. TECHNOLOGIE — AVIS DE CLAUDE AI DEMANDÉ
- Recommandation : Python pour la v1 (écosystème Ren'Py en Python :
  unrpa etc. ; bibliothèques OCR/traduction en Python ; développement
  plus rapide ; packaging : PyInstaller/Briefcase pour Windows,
  fpm/nfpm pour .deb/.rpm, outils AppImage).
- Claude AI doit donner son avis argumenté au démarrage et confirmer
  ou proposer une alternative (ex. Tauri + Rust). Le présent cahier
  des charges s'adapte si une alternative est justifiée techniquement.
- Traduction locale : modèles légers type Argos Translate ou NLLB-200
  distillé quantifié (ONNX/CTranslate2), compatibles 8 Go RAM,
  téléchargés au premier usage ou embarqués (choix à documenter).
- Traduction en ligne : accès Yandex (API officielle ou bibliothèque
  type deep-translator) + moteurs alternatifs configurables.

10. DONNÉES ET CONFIGURATION
- Stockage des données utilisateur (config, thèmes, glossaires,
  profils de jeux) dans le dossier utilisateur système (AppData sous
  Windows, ~/.config sous Linux), avec option portable (à côté de
  l'exécutable).
- Export/import des configurations, glossaires et profils de jeux.
- Sauvegarde automatique des fichiers originaux du jeu avant toute
  modification, avec fonction de restauration.
